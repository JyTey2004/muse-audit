What happens after you ask?

Muse makes the file. A separate checking phase compares it with the saved requirements. The checked result gets a receipt before the file is delivered.

What makes the receipt useful?

It connects the saved request, the version that was checked and the file that was delivered. An old receipt cannot approve a different result.

See the technical workflow

The saved Muse workflow uses separate LLM workers for the work and check phases. The checking worker calls the read-only MCP review. The server recomputes the receipt, then checks the current version again before completion and download. The publisher compares the downloaded bytes with the verified artifact.

The diagram shows selected evidence links. It does not capture every hidden agent action or establish a different-model semantic judge. This demo’s saved receipt, completion and 48-byte result were independently retrieved and matched.
